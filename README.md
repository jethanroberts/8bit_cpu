# 8-bit Verilog CPU (RTL)

Modular 8-bit RISC-style CPU written in Verilog with a controller-driven datapath and full testbench verification using Icarus Verilog + GTKWave.

## Features
- Shared internal bus architecture
- ALU with zero/carry flags
- PC + incrementer
- RAM with MAR interface
- Instruction register
- Parameterized data width
